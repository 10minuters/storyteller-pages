Privacy Policy

StoryTeller uploader · Effective 23 October 2026

The StoryTeller uploader ("the tool") is a personal desktop application used only by the owner of the StoryTeller channels to publish the owner's own videos. It has no other users.

What data the tool uses

  • Account information of the owner's own accounts provided by YouTube, Instagram and TikTok when the owner signs in: the account ID and username, and the basic profile information those platforms return.
  • Access tokens issued by those platforms so the tool can upload videos on the owner's behalf.
  • The owner's own video files and captions, which the tool uploads.

The tool does not collect, read or store data about any other person, including viewers, followers, commenters or other accounts.

How the data is used

The data is used only to upload the owner's videos to the owner's accounts and to check whether an upload succeeded. It is not used for advertising, profiling or any other purpose.

Where the data is stored

Access tokens and logs are stored only on the owner's own computer. Nothing is stored on a server operated for the tool. Tokens can be revoked at any time from the settings of each platform.

Sharing

The data is not sold, rented or shared with anyone. It is sent only to the platform it belongs to (YouTube, Instagram or TikTok) as part of an upload. To let Instagram fetch a video, the video file may be placed briefly at a public GitHub address and removed after the upload.

Retention and deletion

Tokens are kept only while the owner uses the tool and are deleted or revoked when no longer needed. Upload logs contain only video IDs, titles and times.

Contact

Questions about this policy can be sent via the StoryTeller YouTube channel: youtube.com/@StoryTellerSpeaking.
